### Проекты

**[marketplace-sql-warehouse](https://github.com/sfilippov-dev/marketplace-sql-warehouse)**
Витрина данных маркетплейса на PostgreSQL: схема «звезда», 788 тысяч строк
воспроизводимых данных, 15 аналитических запросов с оконными функциями и
замер того, что дают индексы. Ускорение от 684 раз до нуля, и в README
объяснено, почему это два разных класса запросов.
`PostgreSQL` `SQL` `Python` `Docker`

**[phash-dedup](https://github.com/sfilippov-dev/phash-dedup)**
Поиск визуальных дублей изображений: три метода отпечатка и честное сравнение
на наборе, который собирается от зерна. Побайтовый хэш находит 0 дублей из
240, перцептивный 235 без единого ложного срабатывания.
`Python` `numpy` `Pillow`

**[xor-file-processor](https://github.com/sfilippov-dev/xor-file-processor)**
Приложение на C++/Qt: побайтовая обработка файлов в отдельном потоке, пауза и
возобновление, корректное завершение. Интерфейс не блокируется на файлах в
десятки гигабайт.
`C++` `Qt`
