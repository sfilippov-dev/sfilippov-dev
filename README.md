### Проекты

**[unit-economics-engine](https://github.com/sfilippov-dev/unit-economics-engine)**
Юнит-экономика маркетплейса: P&L по каждому артикулу, безубыточный ДРР и решение
по рекламной ставке. На демонстрационных данных находит 3 убыточных артикула из
24, которые забирают 355 тысяч рублей прибыли. Отчёт собирается одним HTML-файлом
без единой внешней загрузки.
`Python` `Decimal` `SVG`

**[api-metrics-collector](https://github.com/sfilippov-dev/api-metrics-collector)**
Сбор метрик из чужих REST API: маркерное ведро вместо повторов после 429, паузы
с разбросом, проверка схемы и идемпотентная запись. Каркас, к которому новый
источник добавляется одним классом на тридцать строк. 65 тестов, ни один не
ходит в сеть.
`Python` `httpx` `asyncio` `SQLite`

**[stock-sync-service](https://github.com/sfilippov-dev/stock-sync-service)**
Сервис синхронизации остатков: FastAPI и PostgreSQL. Повторный вебхук не двигает
остаток второй раз, любая партия правок откатывается одной командой, событие для
внешних систем пишется в той же транзакции, что и само изменение. 38 тестов на
живой базе плюс RUNBOOK для дежурного.
`Python` `FastAPI` `PostgreSQL` `Docker`

**[marketplace-sql-warehouse](https://github.com/sfilippov-dev/marketplace-sql-warehouse)**
Витрина данных маркетплейса на PostgreSQL: схема «звезда», 788 тысяч строк
воспроизводимых данных, 15 аналитических запросов с оконными функциями и
замер того, что дают индексы. Ускорение от 684 раз до нуля, и в README
объяснено, почему это два разных класса запросов.
`PostgreSQL` `SQL` `Python` `Docker`

**[phash-dedup](https://github.com/sfilippov-dev/phash-dedup)**
Поиск визуальных дублей изображений: три метода отпечатка и честное сравнение
на наборе, который собирается от зерна. Побайтовый хэш находит 0 дублей из
240, перцептивный 235 без единого ложного срабатывания.
`Python` `numpy` `Pillow`

**[xor-file-processor](https://github.com/sfilippov-dev/xor-file-processor)**
Приложение на C++/Qt: побайтовая обработка файлов в отдельном потоке, пауза и
возобновление, корректное завершение. Интерфейс не блокируется на файлах в
десятки гигабайт.
`C++` `Qt`
